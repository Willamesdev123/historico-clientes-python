# Sistema de Histórico de Clientes

Sistema desenvolvido em Python para registrar, organizar e consultar o histórico de contatos com clientes.

## Objetivo

Facilitar o acompanhamento dos atendimentos, negociações e providências tomadas, mantendo as informações organizadas para consultas futuras.

## Tecnologias utilizadas

- Python
- Tkinter — interface gráfica
- SQLite — banco de dados

## Funcionalidades

- Registro de contatos com clientes
- Consulta de históricos
- Organização das informações de atendimento
- Registro de providências
- Suporte a anexos

## Sobre o projeto

Projeto pessoal desenvolvido para praticar programação em Python e criar uma solução para organização de atendimentos e rotinas administrativas.

## Privacidade

Este projeto não deve conter bancos de dados reais, documentos de clientes, senhas ou informações confidenciais.
